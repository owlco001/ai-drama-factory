# T001 用户需求（原始）

开发一个安卓App「Agent团队」：
- 本地运行大模型（llama.cpp），无云端依赖
- 层级式多子Agent：1个协调调度Agent + 5个专业子Agent（检索/分析/创作/工具执行/校验）
- 每个子Agent独立System Prompt、独立记忆、工具白名单
- 内部消息总线通信，结构化JSON消息
- UI展示Agent团队面板、任务链路图、执行日志；支持@点名子Agent

MVP范围：单会话串行调度、三层记忆、工具白名单、任务DAG展示。
非目标：并行推理、自定义子Agent编辑器、云端混合。

请产品Agent产出PRD到 docs/prd.md。
