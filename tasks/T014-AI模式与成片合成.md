# T014：首页双模式（AI全托管 / 人工）+ 模型配置 + 成片合成

## 背景
「AI短剧工厂」App（/root/project_workspace/src-ai-drama，Android Kotlin，Compose UI + core-engine 纯Kotlin引擎）。
当前流程全部人工逐步点击。v1.3.0 已有：项目/剧集管理、AI资产提取、AI分镜、渲染队列（断点续传/预算熔断）。

## 需求（老王原话拆解）
1. **APP首页分化两种模式**：
   - **AI模式**：用户只给剧本/小说 → 调用大模型全权处理后续所有环节
     （提取资产→生成图像→质量审计→生成分镜→入队渲染），全程**流式显示进度**
     （每个阶段完成/失败实时推送到UI，类似任务日志流）
   - **人工模式**：保持现有逐页操作流程不变
2. **AI模式需支持选择模型**：常见模型如 DeepSeek 等；沿用现有 Provider 架构
   （AgnesProvider 已实现 TextProvider/ImageProvider/VideoProvider 三通道 + 模型自动选择；
   Hermes 已接入 sensenova 可参考其 base_url/model 配置方式）
3. **成片合成**：目前渲染队列产出单镜 mp4 片段后没有"合成本集成片"功能。
   core-engine 已有 FfmpegAssembler（三级策略 concat-copy/归一化/分段导出，
   JVM 用命令行 ffmpeg），需要接到 App 端：整集镜头 COMPLETED 后一键合成
   单一成片文件，产物落成片库（LibraryPage 目前是空占位）。

  Gradle 依赖；(b) 服务端合成预留接口+端上提示。架构Agent 决策并说明理由。
