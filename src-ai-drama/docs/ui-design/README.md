## 三、设计系统速览

### 色彩（取色唯一来源，页面内禁止硬编码）

| 角色 | 色值 |
|---|---|
| background | `#0D0A1A`（带紫调，非纯黑） |
| surface / variant / highest | `#151022` / `#221A38` / `#241C38` |
| primary 霓虹紫 | `#B388FF` |
| secondary 霓虹青 | `#64E3FF` |
| tertiary 品红 | `#FF7AD9` |
| 正文 / 次级 | `#E8E2F5` / `#B8AECF` |
| success / warning / error | `#57E8A0` / `#FFC24D` / `#FF6B7A` |

对比度：正文 on 背景 ≈ 15:1，次级 on surface ≈ 9:1，均超 WCAG AA 4.5:1。

### 渐变（克制使用，每页 ≤ 3 处）

- `GradHero` `#B388FF → #64E3FF`：标题渐变字 / CTA / 进度条
- `GradAI` `#B388FF → #FF7AD9`：AI 悬浮球 / AI 面板头带

### 字号 / 圆角 / 间距

- 字号：正文基准 **14sp**，全 App 不低于 14sp；12sp 仅辅助说明，11sp 仅角标
- 圆角：徽章 6 / Chip 10 / 按钮 14 / 卡片 18 / 对话框 24
- 间距：4pt 基准（4·8·12·16·24·32·48）
- 触控：所有可点区域 ≥ 44dp

### 三条硬规矩

1. **暗色纵深靠 surface 层级亮度表达**，不用重阴影
2. **禁止卡片套卡片**，卡片内层级用间距 + 1dp 分隔线
3. **状态不靠颜色单独传达**：徽章 = 色底 + 图标 + 文字（色盲可用）

## 四、信息架构改进（本次核心改动）

**底部导航 7 项 → 5 项**，单格由约 52dp 增至约 78dp，消除小屏标签挤压。

| 原底栏项 | 新归属 | 理由 |
|---|---|---|
| 项目 / 资产 / 分镜 / 渲染 / 成片 | 底栏常驻 | 生产动线主干 |
| 剧集 | **项目页二级子页** | 代码里 `onEnterProject` 本就跳 `Page.EPISODES`，它从来就是项目的下一级，不该与项目平级 |
| 设置 | **顶栏齿轮** | 低频，符合 Android 惯例，不占创作动线 |

配套细节：子页显示时底栏高亮映射到所属主标签（避免"无选中项"悬空）；子页顶部有返回箭头；设置页返回进入前的上一个主页面。

已用无头浏览器做点击冒烟，进入/返回链、子页高亮映射、悬浮球、9 格总览全部通过。

## 五、落地到代码：两个必须知道的差距

### 1. 现有主题与规格不一致（重要）

`app/src/main/java/com/dramafactory/app/ui/Theme.kt`（v1.7.2）用的是**另一套色板**：

| Token | 规格要求 | 现有代码 |
|---|---|---|
| primary | `#B388FF` | `#7C4DFF` |
| secondary | `#64E3FF` | `#E040FB` |
| tertiary | `#FF7AD9` | 未定义 |
| surfaceContainer* | 完整 5 级 | 未定义 |
| error / 语义色 | `#FF6B7A` 等 | 未定义 |

即 `UI-BEAUTIFY-SPEC.md` 已写但**尚未落地**。`UI-COMPOSE-THEME.md` 给了完整实现，直接替换 `DarkScheme` 即可，函数签名不变、调用方无感。

> M3 版本为 1.3.0（BOM `2024.10.01`），已支持 `surfaceContainer*`，无需降级替代。

### 2. 底栏改造涉及功能/架构变更

需改 `ui/DramaApp.kt` 的 `Page` 枚举与 `NavigationBar`，详见 `UI-COMPOSE-THEME.md` §7。**`aiVm.onGoto` 跳转表保持 7 项不变**——AI 助手仍要能直接跳任意页。

## 六、落地步骤

1. 建 `app/.../ui/theme/`，放入 `Color.kt` / `Gradient.kt` / `Type.kt` / `Shape.kt`
2. 替换 `ui/Theme.kt` 的 `DarkScheme`
3. 跑 `:app:assembleDebug` 确认编译通过
4. 按 `UI-COMPOSE-THEME.md` §6 检查清单逐页走查
5. 最后做底栏 5 项改造（功能变更，建议单独一个提交）
