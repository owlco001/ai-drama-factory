组件规范要点

  • CTA 主按钮：高 48dp、圆角 14dp、GradHero 渐变底 + 外发光；仅「创建 / 继续渲染 / 保存」等关键动作使用，同屏不超过 1 个。
  • 卡片：圆角 18dp、1dp 描边 outlineVariant；禁止卡片套卡片，卡片内层级用间距与细分隔线解决。
  • 状态不靠颜色单独传达：每个状态徽章 = 色底 + 图标 + 文字，满足色盲可用。
  • 列表：优先用间距与 1dp 分隔线分组，而非每项都套卡片。
  • 触控：所有可点区域 ≥ 44dp（.mini 小按钮视觉 30dp，实际热区用 padding 撑满）。
  • 暗色纵深：靠「越靠上层级，surface 越亮」表达，不用重阴影。
已应用改进 · 底部导航 7 项 → 5 项

问题：7 个平级标签挤在一条底栏，392dp 宽下单格仅约 52dp，图标 21dp + 10.5sp 文字已贴极限，小屏机型会挤压标签。

改法：项目 / 资产 / 分镜 / 渲染 / 成片 5 项常驻，单格约 78dp，留白充足。 「剧集」降为项目页的二级子页——代码里 onEnterProject 本就跳 EPISODES，它从来就是项目的下一级，不该与项目平级； 「设置」移入顶栏齿轮，符合 Android 惯例，且不再占用创作动线。

收益：底栏不再挤压；导航顺序与真实生产流程一致；子页带返回箭头，层级关系明确。

9 个界面状态一览：开屏 → 5 个常驻标签页 + 2 个子页 → AI 助手面板。
